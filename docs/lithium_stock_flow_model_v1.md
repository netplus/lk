# 锂资源研究：存量—流量、交割制度与权益现金模型 V1

研究日期：2026-11-18。状态：方法研究与离线核算原型；不是已校准的预测模型，不提供交易指令。
仓库读取基线：main / ca9209da80ea9ecbda69edfbc1e062d6490758ec。

## 1. 研究结论与需要纠正的解释

建议采用“物料守恒底座 + 供应链时滞 + 交割制度/经济性 + 项目成本 + 权益利润/现金桥 + 情景估值”的组合，而不是用仓单涨跌拟合股价。先确认发生了什么、在哪个边界发生，再预测影响。

有三项重要修正：

1. GFEX 2026-05-28版碳酸锂业务细则第四十条规定3/7/11月末集中注销，满足货龄条件的未出库货物可重新注册。因此11月仓单下降不能直接归因于消费。这里核查的是交易所文件的第三方托管副本，已看封面及印刷页7、12；交易所原链接本次超时。规则事实与本次下降究竟多少由规则导致，是两项不同判断。[R1]
2. 同一固定、互斥、完整覆盖边界内的库存转移，总和不变。盐厂向正极转移本身不能解释该边界总库存下降；加工把碳酸锂变为正极材料时，它可能离开“未加工碳酸锂库存”边界，但仍在锂元素全链库存内。因此“锂盐消耗”和“终端需求”须分开。
3. 仓单分仓库与厂库。厂库注册需履约担保，不能未经核对就等同于特定仓库已锁定实物。仓库仓单也不等于全部可交割商品，注销不等于出库。[R1]

## 2. 理论依据与可移植边界

| 方法 | 本研究采用的部分 | 不采用的过度推断 |
|---|---|---|
| 物质流核算/MFA | 边界、统一物量、存量与流量守恒；内部流动抵销 | 把调查总量当成全国真实库存 |
| 动态MFA和项目级供应模型 | 项目ID、爬坡、地域分配、回收路径 | 名义产能等于未来产量；长期供给潜力等于下季度供应 |
| 储存理论 | 库存、便利收益、仓储资金成本和期限结构联动 | 远月价格是不带风险溢价的未来现货预测 |
| 混频状态空间/即时估计 | 分离经济发生期、披露时间、可用版本；处理异步观测 | 用滤波器“修出”无法识别的真实库存；把估计升级为观测 |
| 权益法与现金核算 | 权益利润、分红、股东借款回收和新增融资分开 | 项目FCF×股权比例等于上市母公司已到账现金 |
| 商品公司情景估值 | 共同矿盐价/汇率路径、成本和资本开支动态化 | 三年均值自动等于正常化利润；低PE自动等于便宜 |

Eurostat提供MFA统计边界的基础。[R2] IEA的矿端供需框架区分一次供应需求、二次供应与冶炼损耗。[R3] 2026年动态MFA研究同时提示其项目供给是潜力情景，未内生纳入价格反馈，并存在中间环节遗漏；这些正是本项目必须补上的限制。[R4] Deaton–Laroque与Gorton等人的储存研究不能直接当作中国锂仓单的已验证经验规律。[R5][R6]

## 3. 模型A：三个独立核算边界

### 3.1 全球资源与全链锂元素账

以锂元素吨作为跨形态基础，显示时才转为LCE；保留原实物吨、含水率、品位和测量基准。节点包括矿端、在途、港口、盐厂原料/WIP、锂盐、正极、电芯、系统交付与使用中存量。每条物流边有唯一ID和起止节点。

I[n,t] - I[n,t-1] = 外部投入[n,t] + Σ内部流入 - Σ内部流出 - 终端边界流出 - 损耗 + 统计调整。

加总相同边界时，内部流动必须成对抵销。回收是使用中/废料节点返回供应链的边，不能既作为新开采又作为同一批中间投入重复计量。境外出口和中国进口可用于交叉验证，但不是全球两份新增供应。

### 3.2 中国商品碳酸锂账

ΔI_CN = 国内商品产量 + 成品进口 - 成品出口 - 投料转化/其他耗用 - 物理损耗 + 统计调整。

必须证明所有项覆盖同一期间、单位和主体范围。进口精矿不再加到国内碳酸锂产量中；它已通过盐厂转化进入产量。硫酸锂是中间品，须进入对应节点，不能按实物吨直接与成品碳酸锂相加。

注意，正极/电芯企业持有的“碳酸锂原料库存”与其“正极/电池成品所含锂库存”不是同一个指标。产品名称和库存形态缺失时不得推断终端去库。

### 3.3 交割账

W_total = W_warehouse + W_factory。
ΔW = 新注册 - 注销 + 已知修正。

若只有净增减，不能倒推出真实新增注册、注销或注销原因。仓单转让/完成交割如果未注销，不必改变W。注销后留库、异地转库、重新注册及进入实际生产必须分开。

对仓库实物，还需跟踪：已注册、已注销未出库、合格未注册、不再符合注册条件四类。厂库仓单单列为交付义务，不能默认嵌入同一物理库存在同一比例中。

## 4. 模型B：品位、含水、回收与时滞

含锂量的直接计算：

contained_LCE = 湿吨 × (1-含水率) × 干基Li2O质量分数 × 73.89/29.88。

recoverable_LCE = contained_LCE × 已验证的后续回收率。

这是含量/可回收量，不是已销售合格产品。品位写6%时输入0.06。若已是精矿产量，不再次扣矿石选矿环节的回收率。生产线产品纯度、合格率和工艺损耗另行记录；缺参数保持缺失或给明确情景范围。

运输可用分布滞后表示：Arrival[t] = Σ Ship[t-l] × k[l]，k非负，完整尾部和为1。对华去向比例和产品回收率分别施加，不藏在同一系数里。输入优先实际发运而不是矿山生产；未发运部分留在矿山库存，未到货部分留在在途库存。

盐厂输出受进料、已验证回收率、有效处理能力及生产约束共同限制。名义能力×开工率只是情景，不是观测。参数应来自季度产销存、海关、真实船期/批次；无逐船数据可保留区间，不制造完整航程。

同样对需求建立“材料生产→电池生产→出货→装车/系统交付”的时滞。正极端耗锂是生产需求，终端装机是终端需求，二者可并行检验但不能相加。出口若包含在销量中不再额外计入。

## 5. 模型C：解释仓单的制度与经济性

逐日字段：规则版本、适用合约、仓库/厂库类型、注册/注销毛流量（缺则空）、注销原因（未披露则未知）、注销截止日、货龄、注销后未出库、重新注册、基准/替代品与区域升贴水。

GFEX已核2026-05-28版中：第三十六条分仓库/厂库；第三十九条基准品60日、替代品240日注册货龄；第四十条3/7/11月末注销及留库重注册；第六十五条厂库担保要求。后续新规必须版本化，不能将新规回填历史合约。[R1]

研究事件时间以距注销日的交易日数对齐，不机械按公历周同比。建议预先锁定[-20,+20]交易日观察窗作为探索协议，并做替代窗口敏感性分析；它不是统计显著性或交易阈值。检验注销前后W、实际出库、下一周期注册、现货基差是否一致。周期很少且与季节性需求重合时不作因果结论。

交割净收益示意：

M_delivery = 同品同地同税基准的可交割远期收入 - 购货成本 - 运输检验 - 仓储 - 资金 - 不可抵扣税费/制度成本。

先比较现售与交割两条实际净收入，不用混合早晚盘/不同报价机构制造基差。库存持有套利关系F≈S×exp((r+u-y)T)只作理论基准；现实残差还混合质量、位置、税、融资、交割选择权和风险溢价，不能全称为便利收益。[R5][R6]

## 6. 模型D：观测层、识别与混频

结构状态x是未必全可见的各环节存量/流量；观测y_s,t来自不同调查商或公告。

y_s,t = H_s,version × x_t + b_s,version + ε_s,t。

H描述样本覆盖和统计边界，不同机构各自一条观测方程。没有样本构成，不能用SMM/Mysteel库存简单求平均来估真实全国库存，不能通过平移曲线掩盖改样本。

实施顺序：先有约束的账面核对和可行区间；待连续数据、修订版本及观测误差可估计后，再试小型混频状态空间或分布滞后模型。ECB有关混频、缺失与发布延迟的方法提供实现参考，但不保证在本项目小样本上有效。[R7]

不可识别时报告“不同原因都能解释现象”，保留竞争假设，不让先验权重替代证据。模型估计区间、模型假设区间和统计置信区间必须分开。

## 7. 模型E：成本曲线与供给响应

分别维护：现金运营曲线、维持性资本支出后曲线、包含扩张回报要求的完全成本/新项目门槛。统一产品、含量、运输边界、币种和税费前不横排成本。

矿价和锂盐价格不是独立任意情景。外采矿盐厂需跟踪库存原料成本与新采购成本，实际售价也有长协滞后；库存减记不等于同期现金流出。项目停产取决于净回款、可避免成本、维护/重启开销、合同与流动性；不能设价格低于现金成本当天全部停产。

对未来1—2季度，使用已投产产线、可售库存、实际发运和检修计划。1—3年则加入项目阶段、融资、许可、建设与爬坡情景。尚未FID的能力只进入条件情景，不计入实际产量。

## 8. 模型F：从资产到上市股东的两张账

利润桥：外销数量×实现售价－销售成本－运营费用－折旧/利息/税费＋权益法收益±减值/汇兑/其他－少数股东损益；合并内部交易抵销。不能先按最终股比缩减全部收入，又扣一次少数股东。

现金桥：各实体期初现金＋经营现金流－维持及扩张资本支出＋新增债务/股权融资－债务本金偿还－已支付分配±其他现金变动＝期末现金。利息/税费若已在OCF中不得再次扣。限制性现金、最低流动性和子公司债务约束须另列。

项目可分配能力不是已宣派分红；已宣派不是已付款；付款至中间控股公司不等于上市母公司到账。股东借款本金回收是现金回收，不是新增利润，可能不可持续；收回现金再投入新项目须另列流出。估值不要求每期全部现金上划，但必须反映获取路径、资本使用和分配约束，不能将未知到账视为零价值。[R8]

天齐具体映射：Greenbushes→Windfield/TLEA→上市主体，配套SQM权益收益/股息、国内盐厂、Kwinana及重大税务事项。赣锋：Mt Marion、Goulamina、Cauchari、Mariana逐项目产销/权益/包销/借款/资本投入；Exar、Exar Capital、LAR与赣锋是不同实体，反向用其他股东到账倒算赣锋需有完整且同口径资金对账，否则拒绝。

仓库已有两条有代表性的未闭合链：TLEA收款与上市主体现金未闭合；Cauchari的项目现金/股东借款回款与赣锋最终到账未闭合。本次仅复用仓库证据状态，没有新增确认现金到账。

## 9. 决策层：共同情景与可证伪论点

先比较资源/资产竞争力，再比较上市公司现金和资本需求，最后才比较价格隐含预期。三者不合并成一个主观总分。

设定一致的矿盐价/汇率/运输/爬坡情景，输出各公司利润和现金的方向与敏感性；资料齐全才生成数值区间。周期中枢应调整产能、股权、成本和资本结构，不取三年简单均值。[R9]

估值可用资产分部法或权益现金法，但同一资产不得既完整资本化其权益利润又重复加入资产价值。反向估值回答“当前价格需要何种锂价、销量、成本和现金分配才能成立”，不是用乐观锂价假设证明股票低估。资料不足只列需要验证的条件，不排名、不生成目标价。

四个竞争解释：
- 终端吸收强：需产销/真实交付和下游库存联合支持；仅仓单减少不支持。
- 矿到盐传导延迟：需矿端/WIP库存和实物到货、有效产线数据；观察增量何时形成销售。
- 仓单制度转换：需到期、货龄、注销后留库、再注册证据；不是默认全部由制度解释。
- 地域/品级分割：需成交品级、进口目的地与长协交付、区域现货证据。

每条论点保存支持/反对证据、未知项、期限、下个验证事件和可能推翻条件。一条可靠且影响足够大的新证据可以触发提前重估，不要求所有风险同时发生。

季度流量保留季度窗口，不复制成三份月度“实际”；月总量可作为日/周潜在量的加总约束，不凭均摊造观测。所有修订追加版本，只有日期的市场研究可用时点仍按已有方法保守置于下一交易日。事后发现早期公告不等于系统当时确实已使用：区分重建的历史信息集和真实运行日志。

数据存储使用CSV/JSON与原始来源目录即可，无复杂数据库、收费runner、自动交易或多Agent平台。

## 12. 验证计划

第一层核算测试：加总、内部转移守恒、缺失≠0、同净额不同毛流量、到期注销不出库、无新增生产的重注册、含水/品位/LCE、滞后尾部、可用时间和现金缺项。
第二层历史回放：预先固定时序训练/验证窗口；任何时点只见当时可用版本；训练折内选择参数，不能先全样本校准再回放。价格/回报研究仍受现有G0–G4门禁。
第三层预测评价：先预测盐厂产量、到港/库存变化和实际现金，不先预测股价。与上一期持平、季节性简单基线、企业指引对比；记录MAE、方向误差、区间覆盖与区间宽度、修订幅度。零值附近不用MAPE。若连续序列不足，不报告稳定准确率/概率。
第四层决策稳健性：不同合理口径、滞后和价格情景是否改变两家公司相对结论；重点补会翻转判断的缺口，而不是只补易取数据。
