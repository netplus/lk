# 周期研究方法 V3 — 价格、量、财报与产业同框

## 1. 研究边界和时间轴

固定初始化时点2026-11-04。行情目标2023-11-04至2026-11-03；2026-11-04盘中数据排除。财报包含2023–2025完整年度和2026已披露Q1/H1/Q3，早于严格三年窗口的2023Q1–Q3只作滚动指标预热。

“三年”是样本窗口，不是预设周期长度。两家公司、约12个主要季度并不等于足够多的独立周期。若完整周期没有覆盖，明确限制；仅为验证上一轮峰谷时才小范围向前延长，不默认扩大股票池。

两条时间轴分别存储：经营发生期(period_end)与公开可用时点(available_at)。年报披露的早期季度表属于annual_retrospective；不能把2024年披露的2023Q1数字放到2023Q1末的可交易信息集。当前来源日期来自本次采用的披露文件，不冒充最早发布时间。只有日期无时分时，保守按下一交易日可用；早报、预告、业绩快报与正式财报分开，后续重述不覆盖旧版本。

## 2. 先描述，再检验，最后形成判断

### A. 价格与成交量

保存原始OHLC、成交额、精确股数成交量、换手率、公司行动和复权版本。原始价格用于真实报价/市值，核验复权用于收益与回撤。前复权历史随除权更新，要记录采集日；未核对分红规则的供应商复权价不得称为含税/税后总回报。两家公司分红、送转、股本和流通股变化分别处理。

基础指标限于周/月收益、滚动波动、最大回撤、相对沪深300表现、20日相对成交量和换手率。相对成交量=当天股数/此前20个有效交易日股数中位数，分母不含当天。停牌/缺失不填0，不拿不完整当日量与全天量比。放量下跌、缩量上涨是描述，不能直接称为主力出货/吸筹。

基准指数需自有来源、相同日期与收益口径。采用价格指数则超额收益明确为价格口径；不能把含分红股票收益与不含分红指数混为投资业绩。

### B. 财务与现金

Q1=Q1累计；Q2=H1-Q1；Q3=9M-H1；Q4=FY-9M。仅同口径可相减，变更先桥接；年报直接列季度值则保留原值和年报版本。资产负债表为时点余额，不能按上述方法处理。TTM需要连续4个可比季度；缺季度留空。

区分主营经营、SQM等权益法收益、公允价值、减值、税率、少数股东；不能用合并OCF/归母净利一个比率判断全部盈利质量。自由现金流要有资本支出，ROIC要有一致投入资本和税后经营利润；未采字段就不计算。

本期已入库的是四项季度核心指标，不是完整三张表。2026余额仅含资产总额和归母权益。资产项目成本、资本开支、债务和权益桥尚未填齐。

### C. 产业周期的独立证据

把锂精矿/锂盐价格、同口径库存变化、实际产销、成本与停复产、终端需求分开建序列。库存改样本使用回溯后数据；矿端产量/精矿进口/盐厂产量不能重复相加。供给响应要区分意向、投产、稳定产量、发运、到港、合格销售。

阶段描述仅作假设：供给扩张/需求放缓、去库存/减产、供需再平衡、需求加速/补库。每一阶段须列支持证据、反证、信息截至时点，不用股价画出的峰谷反向证明产业阶段。无完整产业时间序列时不标注“周期底部已确认”。

### D. 事件研究与领先滞后

财报/预告/重大项目以首次公开时点为事件，不以期末为事件。预先固定观察窗[-1,+1]、[0,+5]、[0,+20]交易日；市场调整收益和[-120,-21]估计窗口的市场模型作为两种可比较方法。缺完整交易日/基准、估计期停牌过多则不计算。

事件重叠、同期政策/商品冲击、预告泄露预期、涨跌停不可成交分别记入。少量事件以描述为主，不能宣称显著因果。相关系数/滞后相关只能检验关联，不证明股价必然提前X个月。不得筛选最漂亮的窗口后将其当预设结果。

### E. 估值与投资判断

不把周期高利润下的低PE等同低估，亏损期PE记不适用。历史PB/EV需当时股价、股本、股权类别、净债务和最新已公开财报，不能用今天资产负债表回填。A/H股市值需分别按各自股本、价格与汇率处理。

正常化利润需要完整周期、资源/产能规模与成本变化解释，三年简单平均只能是描述统计，不自动成为盈利中枢。天齐与赣锋分别进行矿盐权益、资本开支和现金回报桥接，再用统一锂价/矿价/汇率情景比较；不能重复计入资产价值和同一资产收益。

建议按“产业事实→公司传导→估值反映→反证/风险”形成，不因持仓既定而找理由，不因某个技术指标机械下单。

## 3. 验证门禁

G0 原文身份/日期/单位/口径/算术通过；G1 全量日线、公司行动、交易日历和独立抽样核验；G2 财报point-in-time版本及历史股本；G3 产业价格库存经营序列；G4 预先固定方法与时间顺序样本外检验。

当前只通过核心财务G0和网页样本基础形状检查。G1–G4不通过，禁止输出三年回测/胜率/价格领先期/买卖点。未来试验按时间顺序滚动，不随机打散；对照买入持有，计入历史手续费、税费、滑点、停牌和涨跌停约束。少数周期下不提供貌似精确概率。
